5. 目标函数、成本函数、损失函数
	1. 目标函数（objective fucntion）：是训练模型时需要优化的函数，用于衡量模型在当前参数配置下的表现；
		- 目标函数通常是根据模型的预测值与真实值之间的误差来定的，反应了模型的性能和预测误差；
		- 常见的目标函数包括：
			1. 损失函数(loss function)：用于衡量单个样本的误差，比如均方误差和交叉熵损失；单个记录的损失值
			2. 成本函数(cost funciton)：通常用于衡量整个数据集上平均或者总和，是模型在整个训练数据集上的表现度量；整个数据集的损失值
			3. 正则化项：用户控制模型复杂度，防止过拟合；
			**所以成本函数等于损失函数集体和求平均值。**
	2. 优化算法
		通过优化算法，自动调整模型参数，使得目标函数的值最小；  
		常用优化算法：1. 梯度下降算法； 2. 自适应优化算法；
6. 损失函数与优化算法的关系
- 损失函数是优化算法的优化对象；
- 优化算法通过算是函数的梯度来更新参数；
- 优化算法影响损失函数的收敛速度和效果；

7. 过拟合与欠拟合
- 过拟合
	- 模型在训练集上表现很好，在验证集和测试集上表现很差；
	- 这个通常在训练的过程中学习到了噪声，而不是普遍的规律；
- 欠拟合
	- 表现是在训练集合测试集上的表现都不佳；
	- 这可能说明模型过于简单，无法捕捉数据中的复杂模式；

## 神经网络基础

神经元：多个输入、一个输出，触发条件是达到某个阈值；
这里的神经网络与生物神经网络没有什么联系，只是结构比较像；
y = w1x1 + w2x2 + ... wnxn + b
x1, x2 ... xn 是输入，w1，w2， 输入的权重；
b 是偏置；

每次反向传播，是为了调整w1，w2 ...
单个神经元可以理解为一个多元一次方程；
全连接；
输入层 + 隐藏层（可以是多层）+ 输出层
激活函数：他是作用在每个神经元上的；F(y)，为了拟合样本点；

神经网络的学习过程：
前向传播：每个神经元经过激活函数得到一个输出层的预测值y*^
计算损失（根据损失函数或成本函数）：根据预测值y^ ，真实值y，来计算出w1, w2.... 这些权重的调整能够得出更小的L损失；
	损失函数要具有可导性；
优化器：来调整w1 w2等...，他的作用目标是损失函数；

训练的内存比推理要大，就是因为在训练时需要存储大量的权重值；

1. 初始化：随机初始化网络中的所有参数；
2. 前向传播：将样本的各特征（x1, x2...）作为输出，逐层计算后，又最后的输出层生成最终的预测后果。
3. 计算损失：将网络的输出值通样本的标签值进行比较，计算出损失函数（成本函数）的值；
4. 反向传播：通过链式法则，计算损失函数对每个参数的梯度；地图代表着损失函数在当前参数点处变化的最快方向；
5. 参数更新，根据计算得到的梯度，使用优化算法来更新网络中的参数（权重）；
		常用优化算法：随机梯度下降（sgd）、momentum、AdaGrad、adam
6. 重复以上步骤。

神经网络为什么有学习的能力：
	源于数学上的通用逼近性、数据驱动的特征提取、以及结构设计的高度灵活性，
	万能的函数逼近器，神经网络可以通过任意精度逼近任何连续函数；**只要神经元足够多；**
	- 他不具备可解释性；

对这个逼近器（函数）的理解：
参数量的理解：
	神经网络：
		输出层：1024，隐藏层1：2048（神经元） ，隐藏层2：2048，输出层：1
	那么他的参数量是：1024 * 2048 + 2048 + 2048 * 2048 + 2048 +  2048 + 1

每个神经元都需要激活函数来处理吗？
**是的，绝对需要。** 正如你上一个问题所理解的，每一个神经元在完成了 w1x1+w2x2+...+bw1​x1​+w2​x2​+...+b 的线性计算后，**必须**经过激活函数。如果不经过激活，这个神经元就只是一个简单的线性方程，整个网络就失去了“变聪明”的非线性能力。

是一批次的处理必须使用相同的激活函数吗？
是的。同一层内的所有神经元，以及同一批次（Batch）输入的所有样本，在穿过这一层时，使用的绝对是同一个激活函数。


不同层可以用不同的激活函数吗？
**可以，而且非常常见！**  
虽然同一层里大家用的都一样，但**网络的不同层之间是可以换的**。
- **隐藏层**：通常用 ReLU、GELU 或 SwiGLU（为了特征提取）。
    
- **输出层**：必须根据任务换！比如做二分类（是/否），输出层通常用 **Sigmoid**（把值压缩到 0~1 之间）；做多分类（比如预测下一个词），输出层用 **Softmax**（把整个向量变成一个概率分布，所有值加起来等于 1）。
    
- 所以在这个网络里：隐藏层1用的是GELU，隐藏层2用的是GELU，输出层用的是Softmax。但同一层的 2048 个神经元，用的必定都是同一个。

LLM模型的第一层怎么来的？
大模型面对的输入是**文本**（比如：“我爱北京天安门”）。计算机看不懂汉字，所以第一层必须把文本变成数字。这个过程叫**词嵌入（Word Embedding）**。

具体步骤是这样的：
1. **切词（Tokenization）**：模型先用一个叫 Tokenizer 的工具，把句子切成一个个词块（Token）。比如切成 `["我", "爱", "北京", "天安门"]`。
2. **查字典（映射为 ID）**：每个词在模型的词表里都有一个编号。比如“我”是 1024，“爱”是 2048。得到一串 ID：`[1024, 2048, 512, 8192]`。
3. **转化为特征向量（Embedding）**：**这就是大模型第一层真正的“特征”！** 模型会把每个 ID 转换成一个长度固定（比如 4096）的浮点数向量。  
    比如“北京”这个词，可能就变成了这样一个向量：  
    `[0.12, -0.45, 0.88, ..., 0.05]` （总共 4096 个数字）。  
    **这 4096 个数字，就是“北京”这个输入特征！**


在模型内部，有一个极其巨大的二维表格（或者叫矩阵），我们叫它 **Embedding Matrix（嵌入矩阵）**。
每个词的向量维度是 4096。？？？
